# HR Analytics Database

## 📌 Overview
This project contains a MySQL HR Analytics schema and ER diagram.  
All table creation, sample data inserts, and foreign key constraints are included in one script file.

## 📂 Files
- `HR_Analytics.sql` → Full database schema + sample data + queries
- `ER_Diagram.png` → Visual schema design

## 📊 Features
- 8 tables: Employees, Departments, Jobs, Performance, Attendance, Training, Attrition, Projects
- 20 sample records per table
- 10 analytics queries (attrition rate, salary analysis, training completion, etc.)

## 🚀 How to Run
1. Run `HR_Analytics.sql` in MySQL Workbench.
2. View `ER_Diagram.png` for schema design.
3. Use queries at the bottom of the script for analytics.
